TROUBLESHOOTING CHECKLIST
=========================

If you see "ERR_CONNECTION_REFUSED", follow these steps:

1. CHECK IF BACKEND IS RUNNING
   - Look for the "NeuroScanAI Backend" window
   - You should see: "Uvicorn running on http://127.0.0.1:8000"
   - If not, check for error messages

2. CHECK IF FRONTEND IS RUNNING
   - Look for the "NeuroScanAI Frontend" window
   - You should see: "webpack compiled" or "Compiled successfully"
   - If npm start fails, npm dependencies might not be installed

3. VIRTUAL ENVIRONMENT SETUP (Backend)
   If backend window shows errors or exits immediately:
   
   a) Open PowerShell/CMD in the project root
   b) Run these commands:
      cd backend
      python -m venv venv
      venv\Scripts\activate
      pip install -r requirements.txt
   
   c) Test it works:
      python -m uvicorn app.main:app --reload --port 8000
      
   You should see: "Uvicorn running on http://127.0.0.1:8000"

4. NPM SETUP (Frontend)
   If frontend window shows errors or exits immediately:
   
   a) Open PowerShell/CMD in the project root
   b) Run these commands:
      cd frontend\Tumer-Alzheimer-Detection\t-a-det
      npm install
   
   c) Test it works:
      npm start
      
   You should see: "Compiled successfully"

5. PORT CONFLICTS
   If you see "Address already in use":
   
   - Backend port 8000 is in use
   - Frontend port 3000 is in use
   
   To find and kill the process:
   Windows PowerShell: netstat -ano | findstr :8000
   Then: taskkill /PID <PID> /F

6. VERIFY CONNECTIVITY
   After seeing both services running:
   - Wait 10-15 seconds for both to fully initialize
   - Try: http://localhost:8000 (should show {"message": "Backend running"})
   - Try: http://localhost:3000 (should show the React app)
