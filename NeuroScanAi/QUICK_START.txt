QUICK START - 3 WAYS TO RUN
===========================

Choose the method that works best for you:

═══════════════════════════════════════════════════════════════════

METHOD 1: PYTHON SCRIPT (⭐ Recommended - Simplest)
═══════════════════════════════════════════════════════════════════

First time setup (one-time):
    python start.py --setup

Then to run:
    python start.py

✓ Starts both services in one command
✓ Shows clear status messages
✓ Press Ctrl+C to stop both
✓ Works on Windows, Mac, Linux

═══════════════════════════════════════════════════════════════════

METHOD 2: NPM/CONCURRENTLY (For Node.js developers)
═══════════════════════════════════════════════════════════════════

First time setup (one-time):
    npm install
    npm run setup

Then to run:
    npm run dev

✓ Uses popular "concurrently" package
✓ Terminal shows output from both services
✓ Press Ctrl+C to stop both

═══════════════════════════════════════════════════════════════════

METHOD 3: BATCH SCRIPT (Windows only)
═══════════════════════════════════════════════════════════════════

Setup (one-time):
    Double-click: setup.bat (when we create it)

Then to run:
    Double-click: start-app.bat

✓ Double-click to run
✓ Opens separate terminal windows
✓ Close windows to stop

TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════════

If you see errors:

1. "Virtual environment not found"
   → Run: python start.py --setup

2. "npm not found"
   → Install Node.js from nodejs.org

3. "Port already in use"
   → Something else is using port 8000 or 3000
   → Run: diagnose.bat

4. Services start but don't connect
   → Wait 10-15 seconds for full startup
   → Check for errors in the terminal windows
